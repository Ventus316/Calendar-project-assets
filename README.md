# 難哄・日曆 (Nan Hong Calendar)

以電視劇《難哄》為主題的 32 天互動日曆。從收到的人第一次打開網頁的那天算起，往後 32 天每天解鎖一格，對應劇中一集：轉場影片、一句語錄、明日預告，以及藏起來的彩蛋影片。

線上展示：<https://ventus316.github.io/Calendar-project-assets/>

> 非商業同人作品。劇集內容、影片片段與劇照的版權屬原著與製作方。

## 玩法

1. 第一次打開網頁的那天就是 Day 1，之後每天可以多開一格；漏掉的日子可以補看。
2. 點今天的格子 → 轉場（有影片播影片，沒有就用當集封面圖慢慢推近）→ 只出現日期與標題。
3. 點背景 → 有第二段影片就播 → 解鎖語錄與兩張彩蛋圖（點圖看彩蛋影片，沒有影片就全螢幕看圖）。
4. 再點背景 → 彩蛋圖淡出，換成「See you tomorrow」與明日預告。
5. 再點一次關閉，進度 +1。第 32 天看完會出現完結頁。

也可以只用鍵盤：Tab 選日期、Enter 打開，Enter / 空白鍵 / → 進入下一步，影片出現 SKIP 後按 Esc 跳過。

左下角「重置進度」可以只清進度，或連起始日期一起清掉。

### 選集模式

右下角「選集模式」切到 `story.html`：32 集排成一列橫向滑動的選集卡片，滑到中央的那一集放大，上方顯示集數、日期和狀態，背景換成那一集的封面。點中央的卡片打開，點旁邊的卡片先滑到中央。可以用滑鼠滾輪、觸控板、手指滑動或 ← → 鍵切換。

兩個模式共用同一份進度：在哪一頁看過都算。點開某一集之後的轉場、當集卡片和彩蛋圖，兩頁也共用同一套（`episode.js`），畫面和節奏完全一樣。

素材規則是「有影片播影片，沒有就用當集圖片」：

- 轉場：有 `video1` 就播影片，沒有就用 `cover` 封面圖慢慢推近（約 3 秒，可點擊跳過）。
- 彩蛋：有 `video3` / `video4` 就播影片，沒有就全螢幕顯示彩蛋圖。
- 什麼都沒有的集數：卡片顯示集數，打開直接進文字內容；沒有彩蛋圖時語錄和明日預告一起出現。

目前第一集有影片；32 集都已放上封面與兩張彩蛋圖（多數劇照的集數還沒確認，見 `assets/images/SOURCES.md`）。

## 技術重點

- 原生 HTML / CSS / JavaScript，不需要建置工具，直接開 `index.html` 即可。
- **資料與邏輯分離**：32 集文案與素材路徑都在 `assets/js/data.js`，欄位留空就略過（沒有影片用圖片，沒有圖片直接顯示文字）。
- **卡片狀態機**：`episode.js` 的 `detailStep`（0–3）決定點擊背景時要播下一段影片、切換明日預告還是關閉，日曆頁和選集頁共用。
- **雙重解鎖條件**：要「進度到了」且「日子到了」才能開，進度與起始日存在 `localStorage`；點鎖定的日期會提示還要等幾天。
- **只預載一集**：頁面打開時只預載最新解鎖那一集的開場轉場（有影片載影片，沒有就載封面圖），影片也做了 faststart，邊下載邊播。
- **選集列不晃動**：橫向捲動交給 CSS `scroll-snap` 對齊；卡片外框大小固定，縮放只用 `transform`，每幀只讀一次 `scrollLeft`，依卡片序號算距離。
- **無障礙**：鍵盤可完整操作，日期格帶 `aria-label`，支援減少動態效果。
- **自動排版**：依起始日是星期幾決定空格數，並在 5 列與 6 列之間切換。
- **長句換行**：當集卡片的字級隨視窗縮放，長句以標點切段，優先在標點後換行，兩行長度盡量平均。
- **開發者模式**：日曆頁連點右上角製作人名字 5 次、選集頁連點左上角「難哄」5 次，可改 Day 1 日期並無視鎖定。

## 檔案結構

```text
index.html               日曆頁（主頁面）
story.html               選集頁（橫向滑動）
assets/js/data.js        32 集資料與素材路徑
assets/js/progress.js    進度、起始日、解鎖天數（兩頁共用）
assets/js/episode.js     點開某一集：轉場、當集卡片、彩蛋圖（兩頁共用）
assets/js/main.js        日曆頁：渲染日曆、日期格互動
assets/js/story.js       選集頁：選集列、背景
assets/css/episode.css   當集卡片與轉場樣式（兩頁共用）
assets/css/style.css     日曆頁樣式
assets/css/story.css     選集頁樣式
assets/images/           背景與彩蛋圖（WebP）
assets/videos/           轉場與彩蛋影片
prototypes/              早期滑動選集原型（已由 story.html 重做）
DESIGN.md                設計規範
TODO.md                  待辦清單
```

## 本機執行

影片需要透過 HTTP 載入，建議用簡單的本機伺服器：

```bash
npx serve .
```
